## 结论摘要

- 原「业务 / 能力 / 基建 / 跨端」图：**分层思维可用，结构需修正**
- 完整方案采用五层依赖栈 + 跨端作二期策略
- 一期：双端原生 + 共享契约；Feed/IM 按同步系统建设
- 二期：RN 与 KMP **择一为主**

## 建议依赖栈

1. 应用壳 / 导航  
2. 业务模块（Feed、关系、创作、IM…）  
3. 领域服务（同步、媒资、账号会话…）  
4. 平台能力（网络、存储、推送、埋点…）  
5. 工程基建（组件库、崩溃、性能、模块化…）  

跨端不进入上述依赖链。
