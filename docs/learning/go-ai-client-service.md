## 学什么（一句话）

- **Client API（Go）**：App 直连的鉴权、业务 API、BFF、实时与 AI 门面  
- **AI 调用服务（Go）**：多模型适配、流式、限流降级、Prompt/用量/安全  

## 建议顺序

1. Go 工程与 HTTP/API 基础  
2. Client API MVP（账号 / Feed / 契约）  
3. AI Gateway MVP（同步 → 流式 → 限流）  
4. 两服务打通 + 观测与部署  
5. Tool Calling / RAG（按需）
