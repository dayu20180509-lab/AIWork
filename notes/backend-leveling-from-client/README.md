## 适合谁

- iOS / Android / Flutter / RN / 跨端客户端开发者
- 已熟悉网络请求、本地存储、多线程，但缺少「服务端视角」
- 希望系统补齐数据库、缓存、消息队列、分布式与弹性设计

## 怎么用

1. 先读练级文档的「心智模型迁移」与「能力对照表」
2. 按 L0→L5 做项目，对照专栏章节加深
3. 用面试题做自测；不会的题回练级文档对应章节补洞
