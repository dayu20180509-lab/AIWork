# Zoelanguages · 德语学习笔记

> 整理自学习路线截图，并补充可执行的阶段建议。  
> 适用对象：中文母语者，目标从零基础到 B2。

---

## 总路线

| 阶段 | 级别 | 核心目标 |
|------|------|----------|
| 第一阶段 | A1–A2 | 发音打底、高频词、基础语法 |
| 第二阶段 | B1–B2 | 语法巩固、海量输入、开始大量输出 |

学习漏斗（始终按这个顺序滚动推进）：

1. **海量输入**：听力 + 词汇 + 可理解阅读  
2. **基础模块**：教材 / 语法 / 核心句型  
3. **海量输出**：口语对话 + 写作纠错  

---

## 第一阶段：A1–A2（打基础）

### 学习优先级

1. 基础发音（拼读规则、非重读元音）  
2. 高频词汇  
3. 基础语法（性、格、动词变位）  

### 工具与 App

| 类型 | 推荐 |
|------|------|
| 词典 | 德语助手、欧路词典（欧路德语词典） |
| 听力 | 每日德语听力 |
| 官方媒体 | Deutsche Welle（DW）网站 / App |
| 碎片练习 | Duolingo、Busuu |
| 其他 | 罗塞塔石碑（可选，偏沉浸） |

### 发音

- 先掌握字母拼读、长短元音、辅音与双元音  
- 重点练：**拼写→读音规则**、非重读音节  
- 每天跟读 10–15 分钟，宁慢勿糊  

### 核心课程：Nico’s Weg（强烈推荐）

- 来源：[Deutsche Welle · Nico’s Weg](https://learngerman.dw.com/)（A1–B1）  
- 中文讲解补充：沪江「金老师」、每日德语听力「大牛老师」等（按个人习惯选）  

**建议练法：**

1. 先听 / 看（可带字幕）  
2. 填空 / 跟课练习  
3. **影子跟读（Shadowing）**：先慢速有字幕 → 再常速无字幕  
4. 生词进 Excel / Quizlet / Anki  
5. 用「每日德语听力」做听写巩固  

### 教材与课程

- 《Berliner Platz》：体系完整，有中文讲解版，适合打底  
- Lingoda：小班直播课，适合需要外力督促的人  

### 每日节奏（入门）

- **最低配**：15 分钟 Nico’s Weg + 15 分钟词汇/跟读  
- 保持「每天都碰德语」，比周末突击更重要  

---

## A1–A2 语法与词汇要点

### 名词：性 + 格

德语名词必须连 **冠词性别** 一起记（`der / die / das`）。

四格（必须尽早建立直觉）：

| 格 | 德语 | 作用（简化） |
|----|------|----------------|
| 主格 | Nominativ | 主语 |
| 宾格 | Akkusativ | 直接宾语 |
| 与格 | Dativ | 间接宾语 |
| 属格 | Genitiv | 所属（A2 起接触，B1 再系统） |

**方法建议：**

- 用 Excel / 表格按「词 + 冠词 + 复数」收集  
- 例句进 Anki（卡片正面德文句子，背面中文 + 语法点）  
- 不要只背单词表，尽量 **词不离句**  

### 动词：变位 + 时态

- 按人称变位（`ich / du / er…`）  
- A1–A2 先吃透：**现在时 Präsens**、**现在完成时 Perfekt**（口语叙述常用）  
- 方法：每天手写 1–2 个动词变位表，用德语助手核对

## 第二阶段：B1–B2（巩固与输出）

### 学习优先级

1. 巩固语法（从「认识」到「用对」）  
2. 转向 **海量输入**（泛听 / 泛读）  
3. 启动 **海量输出**（口语 / 写作）  

### 材料

| 类型 | 推荐 |
|------|------|
| 课程 | Nico’s Weg B1、继续 Berliner Platz 进阶 |
| 分级新闻 | [Nachrichten leicht](https://www.nachrichtenleicht.de/) |
| 短篇故事 | My German Short Stories 等分级读物 |
| 语法练习 | 《Grammatik aktiv》 |

### 听力方法

- 尽量开 **德语字幕**，少开中字  
- 同一部剧 / 同一播客先跟完一季，建立声音熟悉度  
- 每天固定听力时段（通勤也行）  

### 听力与影视资源

**频道 / 播客**

- Easy German（街头采访，语料真实）  
- German with Jenny / Learn German with Anja（讲解型）  
- Slow German（Annik Rubens）  
- Auf Deutsch gesagt!  
- Tagesschau / Tagesschau in 100 Sekunden  
- Logo! Nachrichten（儿童新闻，更简单）  
- ZDF、Deutsch Podcast、Spotify 德语歌单  

**剧集示例（娱乐输入）**

- Dark  
- How to Sell Drugs Online (Fast)  
- Biohackers  
- 等德语原声内容（先兴趣，再难度）  

**有声书示例**

- 《小王子》德语版  
- 《一个陌生女人的来信》等较熟的故事德译  

### 输出渠道

| 目的 | 平台 |
|------|------|
| 正式课 / 外教 | italki、Lingoda |
| 语伴交换 | HelloTalk、Tandem |

输出原则：**先敢说完整句子 → 再追求格变完美**。每次开口选定 1 个语法点刻意练（如只盯 Dativ）。

### 每日节奏（进阶）

- **标准**：30 分钟核心材料 + 15 分钟听力  
- **加强**：再加泛读 + 精听一段 + 口语 15–20 分钟  

---

## 为什么学德语（动机备忘）

- 哲学 / 社会学 / 文学 / 艺术等一手文献  
- 德国工业、工程、生物医药等职业与学术路径  
- 历史与文化深度（语言是文化的窗口）  

动机写清楚，枯燥的变位期更容易熬过去。

## 补充推荐：一套可直接执行的方案

下面在原笔记基础上，给一个更「省决策」的路线。

### 原则（比选 App 更重要）

1. **一套主线 + 两个辅线**，不要同时开 5 个 App  
2. **词汇必须带冠词与例句**  
3. **A2 前以跟读/听写为主，B1 起强迫输出**  
4. 语法书用来「查缺 + 练习」，不是从头看到尾当小说  

### 主线推荐（按阶段只选一条）

| 阶段 | 主线 | 辅线 |
|------|------|------|
| 0–A1 | Nico’s Weg A1 | 德语助手查词 + Anki |
| A1–A2 | Nico’s Weg A2 + 《Berliner Platz》或《Grammatik aktiv》A1/A2 | 每日德语听力 / Easy German 慢速 |
| A2–B1 | Nico’s Weg B1 + 分级新闻 Nachrichten leicht | italki 每周 1–2 次 |
| B1–B2 | 《Grammatik aktiv》B1/B2 + 原声剧/播客 | 语伴或写作批改 |

### Anki 卡片模板（建议）

**正面**

```text
Ich gebe dem Mann das Buch.
（挖空：dem Mann）
```

**背面**

```text
dem Mann — Dativ（geben 的间接宾语）
der Mann → dem Mann
```

比「Mann = 男人」有效得多。

### 四格最小口语清单（先练熟）

- Akkusativ 常用：`haben / sehen / lesen / brauchen / suchen` + 宾格  
- Dativ 常用：`helfen / danken / gehören / geben / mit / zu / von / bei`  
- 迁移：先背 **介词+格** 搭配，再背孤立规则  

### 每周最小闭环

| 天 | 任务 |
|----|------|
| 每天 | 主线 25–40 分钟 + 听力 15 分钟 |
| 每周 3 次 | 影子跟读 1 段（同一段重复到顺） |
| 每周 1–2 次 | 口语（外教/语伴）或自言自语录音 |
| 每周 1 次 | 语法练习 2–4 页（只做错题回顾） |

### 资源优先级（个人推荐排序）

**必用**

1. [Nico’s Weg（DW）](https://learngerman.dw.com/)  
2. 词典：德语助手 或 欧路  
3. Anki / Quizlet（生词句子化）  

**强烈建议**

4. Easy German（视频）  
5. Nachrichten leicht（B1 起）  
6. 《Grammatik aktiv》  

**按需**

7. italki / Lingoda（要开口或冲考试时）  
8. Duolingo（仅作通勤彩蛋，不当主线）  

### 考试导向（若目标 TestDaF / Goethe）

- A2→B1：先保证听力阅读输入量，再上模考  
- B1→B2：专项练写作结构（Einleitung–Hauptteil–Schluss）与口语提纲  
- 仍建议：**先语言能力，后应试技巧**；裸刷真题效率低
